# Gryzzly Team Composition — финальный пакет воспроизводимости

Репозиторий синхронизирован с финальной версией статьи **«Интенсивная кооперативная игра для формирования состава проектных команд по цифровым следам»**.

Внутри — исходные скрипты финального исследования, point-in-time реконструкция историй кандидатов, rolling-origin валидация, частичное сглаживание, строгие sensitivity-проверки, tie-aware анализ формирования команд и проверка Shapley-атрибуции.

Ключевая финальная конфигурация: окно активности 56 дней, минимум 10 предыдущих деклараций, 90-дневная зрелость исторического результата и τ=5. Итоговая первичная выборка содержит 2 682 проекта; OOF-валидация — 2 107 проектов.

Сырые Gryzzly-данные в репозиторий не включаются. Полный перечень входов и их контрольные суммы находятся в `data/INPUT_MANIFEST.csv`.

Запуск:

```bash
pip install -r requirements.txt
python scripts/run_all.py --stage core
python scripts/run_all.py --stage stageg
python scripts/run_all.py --stage audit
python scripts/validate_results.py
```

Полный текст рукописи намеренно не дублируется: в `paper/` оставлены только финальные метаданные, рисунки и numerical provenance.
