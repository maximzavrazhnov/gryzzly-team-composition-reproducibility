# Data

Raw Gryzzly source tables are **not redistributed** in this repository.

A complete rerun requires the original Gryzzly files listed in `INPUT_MANIFEST.csv`:

- `users.csv`
- `projects.csv`
- `projects_computed.csv`
- `tasks.csv`
- `subscriptions.csv`
- `declarations.zip`

Optional snapshot-completeness inputs used by some diagnostics are documented in the archived package.
Place source files in this directory locally, but do not commit them.

The final submitted study treats `team_id` as a **source-schema workspace**, not as a verified legal organization identifier. Raw-source licensing and redistribution remain governed by the source dataset terms.
